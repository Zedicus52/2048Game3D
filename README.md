# 2048Game3D
This is a prototype of the 2048 game, but with physics and in 3D.

### 🔄 Before vs. After (The Upgrade)

| Feature | Legacy Version | Refactored Version |
| :--- | :--- | :--- |
| **Architecture** | Monolithic scripts, high coupling (spaghetti code) | Clean Architecture, Decoupled Modules |
| **Dependency Management** | Manual Inspector drag-and-drop | **Zenject (Dependency Injection Framework)** |
| **Game Logic** | Tightly coupled with UI and game logic | Strict **MVP (Model-View-Presenter)** / MVC separation |
| **Scalability** | Rigid structure; hard to add features | Highly modular; ready for mechanics extension |
